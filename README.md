# Lo de Liam

Sitio web de **Lo de Liam**, un emprendimiento familiar de productos de limpieza. La página presenta el catálogo, las reseñas de clientes y un formulario de contacto para consultas y pedidos.

Pre-entrega del proyecto de Front End (Talento Tech).

## Contenido

- `index.html`: estructura semántica (`header`, `nav`, `main`, `section`, `footer`).
- `styles.css`: estilos, fuentes de Google Fonts (Baloo 2 y Nunito), Flexbox, Grid y media queries.
- `assets/img/`: logo e imágenes de los productos.

## Secciones

- **Inicio**: presentación del negocio con fondo en degradado.
- **Productos**: cards responsivas con Flexbox.
- **Reseñas**: opiniones de clientes con CSS Grid.
- **Contacto**: formulario conectado a Formspree, adaptable con media queries.
